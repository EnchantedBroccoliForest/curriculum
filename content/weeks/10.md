## Key ideas

- The task is next-character prediction on a small corpus: inputs $x_{1:T}$, targets $x_{2:T+1}$, loss the mean cross-entropy over all $T$ positions in the batch. A uniform predictor over $V$ characters has loss $\ln V$; the bigram model only beats it by learning a $V \times V$ table.
- A batch is a $(B, T)$ integer tensor; the embedding table maps it to $(B, T, C)$; every later tensor keeps the $(B, T, \cdot)$ layout until the logits $(B, T, V)$ are flattened to $(BT, V)$ for the loss.
- A single head: $k = x W_K$, $q = x W_Q$, $v = x W_V$, each $(B, T, d_k)$; scores $q k^\top$ are $(B, T, T)$; the mask is `tril` applied with `masked_fill(mask == 0, -inf)` before softmax over the last axis; output is weights times $v$.
- Multi-head is a list of heads concatenated along the channel axis followed by a linear projection; the head dimension is `n_embd // n_head`, so the total width is preserved.
- The MLP after attention is the per-token computation; attention is the only place tokens communicate. The video's phrase "communication then computation" is the block.
- Residual connections and layer norm are added after the model is already working, and each change is visible as a drop in validation loss at the same step budget; this is the correct way to attribute an architectural change.
- Shapes to recite: `x: (B,T,C)`, `wei: (B,T,T)`, `out: (B,T,head_size)`, `logits: (B,T,V)`, `loss` from `(B*T, V)` against `(B*T,)`.

## Common misconceptions

- "The position embedding tells the model where a token is in the document." → It encodes position within the context window $0..T-1$; the model has no notion of absolute document position.
- "Concatenating heads multiplies the model width by the number of heads." → Each head has width `n_embd // n_head`, so the concatenation restores `n_embd`.
- "Dropout and layer norm are what make the model learn." → The bigram and single-head models already learn; these components improve optimisation and generalisation at the same step count, and the improvement should be measured, not assumed.
