# Week 8: Prince ch. 10–11: convolutions, residuals

## Why this week

Convolutions are the one architectural prior other than attention the plan keeps, at lecture level, and residual connections are why any network deeper than a dozen layers trains at all. The residual stream introduced here is the object the transformer block of [week 9](/week/9) is built around.

## Objectives

- State the convolution as a linear map with weight sharing and locality, and give its parameter count and output shape for given kernel, stride, padding and channels.
- Explain, in terms of the gradient path, why a residual block $h + f(h)$ trains at depths where $f(h)$ alone does not.
- Produce a plot of CIFAR-10 test accuracy against depth from your own run and state what it does and does not show.

## Key ideas

- A 2-D convolution with $C_{\text{in}}$ input channels, $C_{\text{out}}$ output channels and kernel $k \times k$ has $k^2 C_{\text{in}} C_{\text{out}} + C_{\text{out}}$ parameters, independent of image size; output spatial size is $\lfloor (W + 2p - k)/s \rfloor + 1$.
- A residual block computes $h_{\ell+1} = h_\ell + f_\ell(h_\ell)$; the Jacobian $\partial h_{\ell+1}/\partial h_\ell = I + \partial f_\ell / \partial h_\ell$ has an identity term, so gradients reach early layers through a path whose gain is not a product of many small factors.
- Batch normalisation standardises each channel over batch and spatial positions, then applies a learned affine map; inference uses running statistics, so train and test differ and small batches are a problem.
- ResNet's degradation result: a plain 56-layer network has higher training error than a 20-layer one, so the failure is optimisation, not overfitting; the residual connection removes it.

## Common misconceptions

- "Deeper networks overfit, which is why plain 56-layer nets do worse." → The ResNet paper shows higher training error for the deeper plain network; the problem is optimisation.
- "Residual connections add capacity." → A residual block represents anything the plain block can (set $f = g - \mathrm{id}$); the gain is in optimisation conditioning, not the function class.
