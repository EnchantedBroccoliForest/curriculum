## Key ideas

- Judge reliability: a model-graded metric inherits the judge's biases (position, length, self-preference); agreement with humans has to be measured on the same distribution, and the judge must not be the system under test or its sibling.
- Construct validity for agent benchmarks: the benchmark operationalizes "can do knowledge work" as a task set; the question is whether score differences track differences on the tasks a user cares about, which requires an external criterion the benchmark itself cannot supply.
- Prompt injection: text the agent reads (tool output, retrieved documents, web pages) is data that the model may execute as instructions; the trust boundary is between the user's instruction channel and every other input.
- Least privilege: the agent's tools define its blast radius; a read-only tool set bounds what an injection can do.
- The OWASP LLM Top 10 is a checklist of failure classes, not a scoring system; applicability depends on the architecture.

## Common misconceptions

- "A strong model-graded score is evidence of quality." → It is evidence about the judge's preferences; human agreement on the same distribution is the needed check.
- "Prompt injection is a prompt-engineering problem." → It is an architecture problem of trust boundaries and privileges; prompt wording does not enforce a boundary.
