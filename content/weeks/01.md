- Derive the gradients of the ridge and cross-entropy objectives in matrix notation.

## Key ideas

- A **diagnostic** item is passed only if answered closed-book; anything looked up counts as missing. The log is the input to Phase 1, not a score.
- **Reverse-mode AD** on a scalar graph: each node stores its value and a local derivative rule; the gradient of the output $L$ with respect to node $v$ is $\partial L / \partial v = \sum_{u \in \text{children}(v)} \frac{\partial L}{\partial u} \frac{\partial u}{\partial v}$, accumulated in reverse topological order ([week P4](/week/P4)).
- The **chain rule** as bookkeeping: `backward` on node $u$ adds $\frac{\partial L}{\partial u} \cdot \frac{\partial u}{\partial v}$ into `v.grad` for each operand $v$. Gradients must be accumulated with `+=`, because a node used twice receives two contributions.
- Ridge: $\mathcal{L}(w) = \|Xw - y\|_2^2 + \lambda \|w\|_2^2$; cross-entropy for softmax regression: $\mathcal{L}(W) = -\sum_i \log \mathrm{softmax}(W x_i)_{y_i}$. Both gradients are expressions in $X$, residuals and $\mathrm{softmax} - \text{one-hot}$; the softmax Jacobian is what the log-sum-exp identity ([week P3](/week/P3)) keeps finite.
- **SVD versus eigendecomposition**: the SVD $X = U \Sigma V^\top$ exists for every matrix; the eigendecomposition requires a square diagonalisable matrix. Singular values of $X$ are square roots of eigenvalues of $X^\top X$; the condition number $\sigma_{\max} / \sigma_{\min}$ governs how errors in $y$ amplify in the least-squares solution.
- **Likelihood versus posterior**: $p(\text{data} \mid \theta)$ is a function of $\theta$ for fixed data; the posterior $p(\theta \mid \text{data}) \propto p(\text{data} \mid \theta)\, p(\theta)$ is a distribution over $\theta$. Ridge is the MAP estimate under a Gaussian prior.
- **GD versus SGD**: gradient descent uses the full-batch gradient; stochastic gradient descent uses an unbiased minibatch estimate with variance that does not vanish at a fixed step size. Convergence to a neighbourhood, not a point, unless the step decays.
- **Prediction versus intervention**: $E[Y \mid X = x]$ describes what is observed when $X = x$; $E[Y \mid do(X = x)]$ describes what happens when $X$ is set. They coincide only when no confounder affects both.

## Common misconceptions

- Backpropagation is a different algorithm from the chain rule → it is the chain rule evaluated in reverse topological order with intermediate values cached; nothing else.
- The condition number is a property of the data only → it depends on the matrix whose system is solved; ridge changes $X^\top X$ to $X^\top X + \lambda I$ and so changes the conditioning.
- A diagnostic item answered after a quick lookup is "basically known" → in the ledger it is missing; only unaided answers set a level.
