## Key ideas

- A **computation graph** $v_1, \dots, v_N$ with $v_N = L$ scalar: forward mode propagates $\dot v_i = \partial v_i / \partial x$ for one input direction; reverse mode propagates adjoints $\bar v_i = \partial L / \partial v_i$ from the output. For $L : \mathbb{R}^d \to \mathbb{R}$, reverse mode gives the full gradient in one pass at a cost of a small constant times the forward pass; forward mode would need $d$ passes.
- The reverse rule per node: $\bar v_i = \sum_{j : v_i \to v_j} \bar v_j \, \frac{\partial v_j}{\partial v_i}$. For vector-valued nodes this is a **vector-Jacobian product** $\bar v_i = J_{j,i}^\top \bar v_j$; the Jacobian is never formed.
- micrograd's `backward`: set $\bar L = 1$, visit nodes in reverse topological order, call each node's local closure. The order guarantees $\bar v_j$ is complete before it is used.
- **Gradient check**: central differences $\frac{\partial L}{\partial \theta} \approx \frac{L(\theta + h) - L(\theta - h)}{2h}$ with truncation error $O(h^2)$ and rounding error $O(u / h)$; $h \approx 10^{-5}$ in fp64 balances them. Compare with the relative error $\frac{|g_{\text{ad}} - g_{\text{fd}}|}{|g_{\text{ad}}| + |g_{\text{fd}}| + \epsilon}$.
- An **MLP** layer $h = \sigma(Wx + b)$ in micrograd is a list of `Neuron` objects each holding scalar `Value` weights; the loss over a batch is a `Value`, so one `backward` call gives every weight's gradient.
- **Training step**: $\theta \leftarrow \theta - \eta \nabla_\theta L$, after zeroing gradients. Forgetting to zero accumulates stale gradients across steps, a bug the `+=` in `backward` makes possible.
- makemore's **bigram model** has a $27 \times 27$ table of logits; the probability of the next character given the current one is a softmax row; training minimises the average negative log-likelihood ([week P5](/week/P5)), and the count-based estimate is the same model with a closed-form solution.
- A random initialisation whose logits are too large gives a confidently wrong model with loss far above $\log 27$; this is the first appearance of the initialisation-scale question that [week 6](/week/6) treats precisely.

## Derivation or exercise, stated in full

Gradient check against finite differences; one-page backprop-as-reverse-mode-AD derivation

1. **Gradient check.** Build a micrograd MLP (for example $3 \to 4 \to 4 \to 1$) with tanh units and a squared-error loss on a batch of four inputs. For every parameter $\theta_k$ compute (a) the autograd gradient from `backward` and (b) the central-difference estimate with $h = 10^{-5}$. Report the maximum relative error over all parameters, and repeat with $h = 10^{-2}$ and $h = 10^{-9}$, explaining the pattern in the errors.
2. **One-page derivation.** In your own notation, define a computation graph with scalar or vector nodes and a scalar output $L$. State and prove the reverse-mode recurrence for adjoints, show that evaluating it in reverse topological order computes $\nabla_x L$ for all inputs $x$ in one pass, and bound its cost relative to the forward pass. Identify where each ingredient appears in micrograd's `backward` and in the `_backward` closures. State explicitly what is cached from the forward pass and why.
3. **makemore part 1** is watched, not coded: note the loss of the uniform model ($\log 27$), the count-based bigram loss, and the gradient-based bigram loss, and explain why the last two agree.

Assumptions: fp64 arithmetic for the check; a fixed random seed so the two gradient computations see the same parameters.

## Common misconceptions

- A passing gradient check proves the model will train → it proves the gradient is correct for that graph and those values; it says nothing about the loss landscape, step size or initialisation.
- Backward pass cost is "about the same as forward" by convention → it follows from each local Jacobian product costing a constant multiple of the forward operation that produced the node.
- The one-page derivation is about neural networks → it is about any differentiable program with a scalar output; the network is one instance.
