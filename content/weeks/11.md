## Key ideas

- Training: AdamW on the cross-entropy over all positions, with periodic estimation of train and validation loss on fixed random batches; the validation curve is the only thing that decides whether a change helped.
- Sampling: autoregressive generation feeds the model its own output, cropping the context to the block size; the generated text's quality is bounded by the corpus, the model size and the training budget, in that order.
- Rotary position embeddings (RoPE) rotate query and key vectors by a position-dependent angle so that $q_m^\top k_n$ depends on $m - n$; this replaces an additive learned position table and makes relative position enter the attention score directly.
- RMSNorm divides by the root-mean-square of the features without subtracting the mean and with no bias; it is cheaper than layer norm and, in current decoders, used without a learned bias term.
- SwiGLU replaces the two-matrix MLP with a gated form $W_2\,(\mathrm{SiLU}(W_1 h) \odot W_3 h)$; three matrices instead of two, usually with a reduced hidden width to hold the parameter count roughly constant.
- Other differences to look for in the model file: removal of biases, weight tying between the embedding and the output head, grouped or multi-query attention for KV-cache size, the choice of vocabulary size, and where normalisation sits relative to the residual add.
- Decoding strategies: greedy takes the argmax; temperature $\tau$ samples from $\mathrm{softmax}(z/\tau)$; top-k truncates to the $k$ most probable tokens then renormalises; top-p truncates to the smallest set with cumulative probability $\ge p$. Beam search keeps the $b$ highest-scoring partial sequences and is a search, not a sampler.
- GPT-2 is a decoder trained on next-token prediction; BERT is an encoder trained on masked tokens with bidirectional attention; ViT applies the encoder block to image patches as tokens. Same block, three training objectives.

## Common misconceptions

- "A lower temperature makes the model more accurate." → It makes the sampled distribution sharper around the model's own mode; if the mode is wrong, low temperature is confidently wrong.
- "BERT and GPT differ in architecture." → The block is the same; they differ in the attention mask (bidirectional versus causal) and the training objective (masked tokens versus next token).
- "SwiGLU adds parameters because it has three matrices." → Implementations usually shrink the hidden width (for example to about $\tfrac{8}{3} d$) so the parameter count matches the two-matrix MLP; check the model file rather than assume.
