# Week P1: Programming 1: variables, control flow, functions, strings, lists, dictionaries

## Why this week

Every later week assumes you can read and write short Python programs without help. This week supplies the vocabulary: how a program stores values, repeats work, and packages a computation under a name. [Week P2](/week/P2) builds classes and arrays on top of it, and [week 1](/week/1) asks you to code along with micrograd, which is ordinary Python of exactly this kind.

## Objectives

- Write, from a blank file, a program that reads input, loops over it, and prints a result, without consulting an example.
- State what a variable, a function, a list and a dictionary are, and when each is the right container.
- Predict the output of a ten-line program involving a loop, a conditional and a function call before running it.

## Key ideas

- A **program** is a finite list of instructions executed top to bottom. The **interpreter** (the `python` command) reads the text and performs each instruction in turn.
- A **variable** is a name bound to a value: `x = 3` binds the name `x` to the integer 3. Unlike a mathematical variable it can be rebound later; `x = x + 1` is an assignment, not an equation.
- **Types**: integers (`int`), floating-point numbers (`float`, see [week P3](/week/P3)), text (`str`, a string), truth values (`bool`). Python checks types at run time, so `"3" + 3` is an error, not 6.
- **Control flow** decides which instruction runs next: `if` / `elif` / `else` chooses a branch on a boolean; `for x in collection:` runs a body once per element; `while condition:` repeats until the condition is false. Indentation marks the body; it is syntax, not style.
- A **function** is a named, parameterised block: `def f(n): ... return value`. **Calling** it, `f(5)`, binds `n` to 5, runs the body, and hands back the `return` value. A function that calls itself is **recursive**; it needs a base case, exactly as an inductive definition does.
- A **list** `[1, 2, 3]` is an ordered, mutable sequence indexed from 0: `xs[0]` is the first element, `len(xs)` its length, `xs.append(v)` extends it. Slicing `xs[a:b]` takes indices $a, \dots, b-1$.
- A **dictionary** `{key: value}` is a finite map from hashable keys (strings, numbers, tuples) to values; lookup `d[k]` and membership `k in d` take constant expected time ([week P4](/week/P4) explains why). Iterating a dictionary visits its keys.
- **Strings** are immutable sequences of characters; `s.split()`, `s.lower()`, `s.strip()` return new strings. Reading a **file** means asking the operating system for its contents: `with open(path) as f: text = f.read()`.

## Derivation or exercise, stated in full

Five small programs without an agent: prime sieve, word count, a recursive function, a dictionary lookup, a file read

Write each program yourself, in a plain text editor, without an AI assistant or copied code. Documentation lookups are allowed; copying a solution is not.

1. **Prime sieve.** Given an integer $N \ge 2$ typed by the user, print every prime $p \le N$ using the sieve of Eratosthenes: a list of $N+1$ booleans, initially true, with multiples of each prime marked false.
2. **Word count.** Read a text file whose path is given on the command line and print the ten most frequent words with their counts, case-insensitive, punctuation stripped.
3. **A recursive function.** Implement one of: factorial, Fibonacci, or the binomial coefficient $\binom{n}{k}$ via Pascal's rule $\binom{n}{k} = \binom{n-1}{k-1} + \binom{n-1}{k}$, with an explicit base case. Print $f(20)$.
4. **A dictionary lookup.** Build a dictionary from a list of (name, value) pairs; prompt for a name; print the value, or a clear message if the name is absent, without the program crashing.
5. **A file read.** Read a file line by line, count its lines and non-empty lines, and print both counts.

Each program should run from the command line with `python name.py` and finish without an error message.

## Self-check

1. What is the difference between `x == 3` and `x = 3`, and what does each evaluate to or do?
2. Why does `for i in range(5)` visit 0 through 4 and not 1 through 5, and what is `range(2, 10, 3)`?
3. A list and a dictionary can both hold five numbers. Name one operation that is cheap on one and expensive on the other.

## Common misconceptions

- A variable is an unknown to solve for → in a program it is a labelled storage location whose contents change as instructions run.
- `return` and `print` do the same thing → `print` writes text to the screen; `return` hands a value back to the caller so other code can use it. A function that only prints returns `None`.
- Indentation is cosmetic → in Python it defines which lines belong to a loop, branch or function; a mis-indented line changes the program's meaning.
