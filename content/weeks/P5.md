# Week P5: Information theory: entropy, cross-entropy, KL, mutual information, source coding

## Why this week

Every loss function in the programme is written in this vocabulary: the training loss of a language model is a cross-entropy, its reported quality is a perplexity, and the KL divergence appears in the ELBO ([week 12](/week/12)), the RLHF objective ([week 28](/week/28)) and DPO ([week 30](/week/30)). The week closes the primer with Gate P.

## Objectives

- State the definitions of entropy, cross-entropy, KL divergence and mutual information and the inequalities relating them, with the conditions for equality.
- Explain, in terms of code lengths, what a model's cross-entropy loss and perplexity measure.
- Pass Gate P: redo the P3 and P5 exercises closed-book.

## Key ideas

- For a distribution $p$ on a finite alphabet, the **entropy** $H(p) = -\sum_x p(x) \log p(x)$ is the expected code length, in bits if the log is base 2, of the shortest uniquely decodable code for symbols drawn from $p$ (source coding theorem; the bound is achieved to within one bit by Huffman coding and asymptotically by arithmetic coding).
- A **code** assigns each symbol a binary string; a prefix code has no codeword that is a prefix of another. Kraft's inequality $\sum_x 2^{-\ell(x)} \le 1$ characterises achievable codeword lengths $\ell(x)$, so a code is a distribution $q(x) = 2^{-\ell(x)}$ and vice versa: the ideal length of $x$ under model $q$ is $-\log_2 q(x)$.
- **Cross-entropy** $H(p, q) = -\sum_x p(x) \log q(x)$ is the expected code length when symbols come from $p$ but the code was designed for $q$. **KL divergence** $D_{\mathrm{KL}}(p \,\|\, q) = \sum_x p(x) \log \frac{p(x)}{q(x)} = H(p,q) - H(p) \ge 0$, with equality iff $p = q$ (Gibbs' inequality); it is the excess code length paid for using the wrong model. It is not symmetric and not a metric.
- A language model is a code: training minimises the empirical cross-entropy
  $$\mathcal{L} = -\frac{1}{N}\sum_{t=1}^{N} \log q(x_t \mid x_{<t}),$$
  the average number of nats (or bits) the model spends per token. Minimising it over $q$ is minimising $D_{\mathrm{KL}}(p \,\|\, q)$ for the data distribution $p$, since $H(p)$ does not depend on $q$.
- **Perplexity** is $\exp(\mathcal{L})$ with $\mathcal{L}$ in nats: the effective number of equally likely choices per token. Perplexity depends on the tokenisation, so two models are comparable only on the same tokenizer or after converting to bits per byte.
- **Entropy rate** of a stationary source is $\lim_{N \to \infty} \frac{1}{N} H(X_1, \dots, X_N)$; it is the floor below which no model's per-token cross-entropy on that source can go.
- **Mutual information** $I(X; Y) = D_{\mathrm{KL}}(p(x,y) \,\|\, p(x)p(y)) = H(X) - H(X \mid Y) \ge 0$, the reduction in code length for $X$ from knowing $Y$. Conditioning never increases entropy on average.
- A **tokenizer** maps text to a sequence of symbols from a fixed vocabulary; byte-pair encoding ([week 18](/week/18)) merges frequent byte pairs. Fewer tokens for the same text at the same per-token loss means fewer bits spent, so a tokenizer is a (lossless) compressor whose quality is measured in bytes per token.

## Derivation or exercise, stated in full

Cross-entropy as code length; perplexity as exp(entropy rate); tokenizer as compressor. Gate P: P3 and P5 redone closed-book

1. **Cross-entropy as code length.** Prove Gibbs' inequality $H(p, q) \ge H(p)$ from $\log t \le t - 1$, and state the equality condition. Then, taking the code lengths $\ell(x) = \lceil -\log_2 q(x) \rceil$, show using Kraft's inequality that a prefix code with these lengths exists and that its expected length under $p$ lies in $[H(p,q),\, H(p,q) + 1)$.
2. **Perplexity as $\exp$(entropy rate).** For a stationary ergodic source, define the entropy rate and show that the per-token cross-entropy of the true distribution converges to it. Conclude what the perplexity of a perfect model would be, and explain why a model's perplexity is an upper bound on $\exp$ of the entropy rate. State why perplexities under different tokenizers are not comparable and give the quantity that is.
3. **Tokenizer as compressor.** Argue that a tokenizer plus a probabilistic model over tokens defines a lossless compressor via arithmetic coding, and express the compressed size of a text in terms of the model's cross-entropy and the token count. Explain what changes about the compressed size when the vocabulary grows from $2^{15}$ to $2^{17}$ entries if the per-token loss is unchanged.
4. **Gate P.** Redo the [week P3](/week/P3) exercise (all four parts) and parts 1–3 above closed-book: notes shut, calculator allowed, no AI help. Record the date and what you could not reproduce.

## Self-check

1. A model reports perplexity 8 on a test set. How many bits per token is that, and what does the number mean in terms of equally likely alternatives?
2. $D_{\mathrm{KL}}(p \,\|\, q)$ versus $D_{\mathrm{KL}}(q \,\|\, p)$: when $q$ has mass where $p$ has none, which one is infinite, and which one is minimised when fitting $q$ to data from $p$?
3. Two models are trained on the same text with tokenizers of vocabulary sizes 32k and 128k. Model B reports lower perplexity. What must you check before concluding it is the better model?

## Common misconceptions

- Entropy measures disorder → it measures the expected code length needed to describe draws from a distribution; the "disorder" reading is a metaphor that does not survive calculation.
- KL divergence is a distance → it is non-negative and zero iff the distributions agree, but it is asymmetric and violates the triangle inequality.
- Lower perplexity always means a better language model → only at fixed tokenizer and data; perplexity is tokenizer-dependent, and bits per byte is the comparable quantity.
